# Linux and Shell

Filesystem hierarchy, permissions and ownership, users and groups, processes and signals, package management, systemd services, cron, log management (journald, rsyslog), shell scripting (bash), text processing (grep, awk, sed), networking utilities (ss, ip, tcpdump, curl), performance tools (top, htop, vmstat, iostat, strace)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
