# Networking for Infrastructure

OSI and TCP/IP, IP addressing and CIDR, subnetting, routing tables, NAT, DNS (records, resolution, TTL), DHCP, load balancers (L4 vs. L7), reverse proxies (Nginx, HAProxy, Envoy), VPNs, firewalls and security groups, TLS certificates and PKI, Let’s Encrypt, HTTP/2 and gRPC behavior

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
