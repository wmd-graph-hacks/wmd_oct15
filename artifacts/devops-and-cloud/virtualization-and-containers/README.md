# Virtualization and Containers

Hypervisors (Type 1 vs. Type 2), virtual machines, Linux namespaces (PID, network, mount, user), cgroups, container images and layers, Dockerfiles, container registries, OCI standards, container runtimes (containerd, runc), multi-stage builds, container networking

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
