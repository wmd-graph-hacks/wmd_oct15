# Monitoring and Observability

Metrics (Prometheus, PromQL, exporters), dashboards (Grafana), logging stacks (ELK, Loki), distributed tracing (Jaeger, Tempo, OpenTelemetry), alerting design and alert fatigue, SLI/SLO/SLA definitions, synthetic monitoring, real user monitoring, cost observability

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
