# Infrastructure as Code

Declarative vs. imperative infrastructure, Terraform (providers, resources, state, modules, workspaces, remote backends, plan and apply lifecycle), Ansible (inventories, playbooks, roles, idempotency), CloudFormation, Pulumi, configuration management, drift detection

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
