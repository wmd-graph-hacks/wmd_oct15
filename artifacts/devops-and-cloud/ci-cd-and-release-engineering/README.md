# CI/CD and Release Engineering

Pipeline design (build, test, scan, package, deploy), artifact management, semantic versioning, GitOps (Argo CD, Flux), deployment strategies (rolling, blue-green, canary, shadow), feature flags, database migration strategies (expand-contract), rollback procedures, environment promotion, trunk-based development

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
