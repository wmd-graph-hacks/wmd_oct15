# Container Orchestration (Kubernetes)

Architecture (control plane, kubelet, etcd, scheduler), pods, deployments, ReplicaSets, services (ClusterIP, NodePort, LoadBalancer), ingress controllers, ConfigMaps and Secrets, StatefulSets, DaemonSets, Jobs and CronJobs, persistent volumes and claims, storage classes (CSI), resource requests and limits, horizontal and vertical pod autoscaling, cluster autoscaling, RBAC, network policies, CNI plugins, Helm charts, Kustomize, custom resources and operators, Kubernetes troubleshooting

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
