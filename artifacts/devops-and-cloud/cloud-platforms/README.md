# Cloud Platforms

Core concepts across AWS, GCP, and Azure: compute (VMs, autoscaling groups, serverless functions), object and block storage, managed databases, virtual networks and subnets, IAM and identity federation, load balancing, managed Kubernetes (EKS, GKE, AKS), message services, cost management, multi-region and multi-account architecture, landing zones

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
