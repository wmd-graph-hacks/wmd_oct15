# Site Reliability Engineering (SRE)

Error budgets, toil reduction, incident management, postmortems (blameless), on-call design, capacity planning, load shedding, graceful degradation, chaos engineering (Chaos Monkey, Litmus), game days

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
