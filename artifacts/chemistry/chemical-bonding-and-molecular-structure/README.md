# Chemical Bonding and Molecular Structure

Ionic and covalent bonding, Lewis structures, formal charge, resonance, VSEPR theory, molecular geometry, hybridization, polarity, intermolecular forces (London dispersion, dipole-dipole, hydrogen bonding), molecular orbital theory, bond order, band theory (intro)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
