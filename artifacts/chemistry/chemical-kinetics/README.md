# Chemical Kinetics

Reaction rates, rate laws and reaction order, integrated rate laws, half-life, reaction mechanisms, rate-determining steps, collision theory, activation energy, Arrhenius equation, catalysis (homogeneous, heterogeneous, enzymatic)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
