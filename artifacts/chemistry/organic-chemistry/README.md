# Organic Chemistry

Structure and bonding in organic molecules, nomenclature (IUPAC), functional groups, isomerism (structural, geometric, optical), stereochemistry (R/S configuration, chirality, enantiomers, diastereomers), conformational analysis, reaction mechanisms (SN1, SN2, E1, E2, electrophilic and nucleophilic addition, carbonyl chemistry, aldol, Grignard, Wittig), aromaticity and electrophilic aromatic substitution, pericyclic reactions (Diels-Alder, electrocyclic), radical reactions, protecting groups, retrosynthetic analysis, multi-step synthesis

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
