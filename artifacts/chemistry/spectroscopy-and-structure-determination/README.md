# Spectroscopy and Structure Determination

Nuclear magnetic resonance (1H and 13C NMR, chemical shift, coupling constants, 2D NMR), infrared (IR) spectroscopy, mass spectrometry (fragmentation patterns), UV-Vis spectroscopy, combined spectral interpretation

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
