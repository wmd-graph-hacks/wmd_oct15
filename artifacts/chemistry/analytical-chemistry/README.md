# Analytical Chemistry

Gravimetric and volumetric analysis, titration methods, chromatography (GC, HPLC, TLC), spectroscopic methods (UV-Vis, atomic absorption, ICP), electroanalytical methods (potentiometry, voltammetry), mass spectrometry in analysis, method validation, statistical quality control, calibration curves

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
