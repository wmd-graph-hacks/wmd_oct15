# Inorganic Chemistry

Periodic table trends in depth, coordination chemistry (ligands, coordination numbers, geometries), crystal field theory, ligand field theory, isomerism in coordination compounds, organometallic chemistry (metal-carbon bonds, catalysis such as Wilkinson’s and Ziegler-Natta), bioinorganic chemistry (metalloproteins), solid-state chemistry (crystal structures, defects, semiconductors)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
