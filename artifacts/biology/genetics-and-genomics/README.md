# Genetics and Genomics

Mendelian inheritance, linkage and recombination, chromosome mapping, sex-linked traits, pedigree analysis, population genetics (Hardy-Weinberg equilibrium, drift, gene flow, selection), quantitative genetics, heritability, genome structure, genome sequencing (short and long-read), genome-wide association studies (GWAS), CRISPR-based gene editing

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
