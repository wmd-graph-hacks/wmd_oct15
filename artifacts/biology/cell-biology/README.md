# Cell Biology

Cell theory, prokaryotic vs. eukaryotic cells, membrane structure and the fluid mosaic model, membrane transport (passive, active, facilitated), organelles (nucleus, ER, Golgi, mitochondria, lysosomes, peroxisomes), cytoskeleton (actin, microtubules, intermediate filaments), cell cycle and checkpoints, mitosis and meiosis, cell signaling pathways (GPCRs, receptor tyrosine kinases, second messengers), apoptosis and necrosis, extracellular matrix, cell junctions

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
