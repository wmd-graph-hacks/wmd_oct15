# Neuroscience (Introductory)

Neuron anatomy, ion channels and resting membrane potential, synapse types and neurotransmitters, neural circuits, sensory systems, motor control, learning and memory mechanisms (LTP), brain organization

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.

## Subtopics

- [sensory systems: mechanisms and methods](./sensory-systems/README.md) (`biology-neuroscience-introductory-sensory-systems`)

## Assessment evidence

Ask the learner to explain one concept without notes, work a changed example, and identify an assumption or limitation.
