# Laboratory and Computational Techniques

Microscopy (light, fluorescence, electron), cell culture and aseptic technique, PCR and qPCR, gel electrophoresis, Western blotting, ELISA, flow cytometry, DNA sequencing, bioinformatics (sequence alignment with BLAST, genome annotation, RNA-seq analysis), statistical analysis of biological data, lab safety and ethics

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
