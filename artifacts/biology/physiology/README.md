# Physiology

Homeostasis and feedback loops, nervous system (action potentials, synaptic transmission, sensory and motor pathways), cardiovascular system, respiratory system, renal system and fluid balance, digestive system, endocrine system and hormone signaling, musculoskeletal physiology, reproductive physiology

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
