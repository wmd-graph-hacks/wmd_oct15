# Immunology

Innate immunity (pattern recognition receptors, inflammation, complement), adaptive immunity (T cells, B cells, antigen presentation, MHC), antibody structure and function, immune tolerance, hypersensitivity, vaccines, immunodeficiencies, autoimmunity

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
