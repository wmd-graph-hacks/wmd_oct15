# Evolutionary Biology

Natural selection, genetic drift, adaptation, speciation mechanisms, phylogenetics and tree-building methods, molecular clocks, coevolution, origin of life, evolutionary developmental biology (evo-devo), human evolution

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
