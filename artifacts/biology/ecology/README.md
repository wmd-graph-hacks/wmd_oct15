# Ecology

Population dynamics (growth models, carrying capacity, metapopulations), species interactions (predation, competition, mutualism, parasitism), community ecology (diversity, succession, food webs), ecosystem ecology (energy flow, nutrient cycling, carbon, nitrogen, and phosphorus cycles), biogeography, conservation biology, climate-biosphere interactions

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
