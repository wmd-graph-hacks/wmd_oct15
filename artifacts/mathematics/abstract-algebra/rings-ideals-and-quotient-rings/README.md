# Rings, Ideals, and Quotient Rings

A ring has addition and multiplication with distributivity; conventions differ on whether it must have a multiplicative identity or be commutative, so state the convention. Examples include integers, matrices, and polynomial rings. Units have multiplicative inverses. Zero divisors are nonzero elements whose product can be zero.

An ideal I is an additive subgroup closed under multiplication by any ring element. Ideals permit quotient rings R/I, where elements differing by an ideal element are identified. Ideals in rings play a role analogous to normal subgroups in groups. In a commutative ring, maximal ideals produce field quotients; prime ideals produce integral-domain quotients.

**Example.** In ℤ, nℤ is an ideal. The quotient ℤ/nℤ consists of residue classes. For n=6, [2][3]=[0], so [2] and [3] are nonzero zero divisors. When n is prime, every nonzero residue has an inverse, so ℤ/pℤ is a field.

The ideal generated by a is (a)={ra:r∈R} in a commutative ring. In ℤ, every ideal is nℤ; in more complicated rings not every ideal is generated by one element. Quotient operations are well-defined because the set being collapsed is an ideal.

## Lesson: ideals and arithmetic modulo an ideal

A ring has addition and multiplication, usually with additive inverses and associative multiplication; conventions about identity and commutativity should be stated. An ideal I is an additive subgroup absorbing multiplication by ring elements: r·a∈I. Ideals are the ring analogue of normal subgroups and permit quotient rings R/I, where elements are additive cosets and multiplication is well-defined.

In ℤ, every ideal is nℤ. The quotient ℤ/nℤ is modular arithmetic. A quotient by a prime ideal is an integral domain; a quotient by a maximal ideal is a field. In commutative rings with identity, maximal ideals are prime, though converse need not hold.

**Worked example.** In ℤ, consider 5ℤ. The quotient classes [0]…[4] add and multiply mod 5. Because 5 is prime, every nonzero class has a multiplicative inverse, so ℤ/5ℤ is a field. In ℤ/6ℤ, [2] is a zero divisor since [2][3]=[0], so it is not a field.

**Practice with answers.** (1) 2ℤ is an ideal of ℤ. (2) 5 has inverse 2 mod 9 because 5·2=10≡1. (3) 2 has no inverse mod 6. (4) The quotient construction requires an ideal, not an arbitrary subset.

**Common pitfalls:** confusing subrings with ideals; assuming every nonzero residue has an inverse modulo composite n; and using a quotient operation without checking representative independence.
