# Abstract Algebra

Symmetry and algebraic operations studied through groups, rings, and fields.

## Learning outcomes

- Explain and apply the core ideas in **Groups, subgroups, cosets**.
- Explain and apply the core ideas in **Normal subgroups and quotients**.
- Explain and apply the core ideas in **Isomorphism theorems and actions**.
- Explain and apply the core ideas in **Sylow theorems**.
- Explain and apply the core ideas in **Rings, ideals, and quotient rings**.
- Explain and apply the core ideas in **Domains, PIDs, UFDs, polynomial rings**.
- Explain and apply the core ideas in **Fields, extensions, Galois introduction**.
