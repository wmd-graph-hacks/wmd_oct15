# Partial Differential Equations

Equations involving partial derivatives, boundary conditions, and spatial modes.

## Learning outcomes

- Explain and apply the core ideas in **Heat, wave, and Laplace equations**.
- Explain and apply the core ideas in **Separation of variables and Fourier series**.
- Explain and apply the core ideas in **Sturm–Liouville problems**.
- Explain and apply the core ideas in **Boundary/initial value problems and Fourier transforms**.

## Assessment evidence

A learner should be able to solve representative problems without hints, explain why the method applies, identify assumptions, and check the result. Suggested evidence: a short diagnostic, a worked solution with reasoning, and a spaced-retrieval check after several days.
