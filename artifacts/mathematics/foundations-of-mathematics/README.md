# Foundations Of Mathematics

Language, structure, and proof habits used throughout mathematics.

## Learning outcomes

- Explain and apply the core ideas in **Logic and quantifiers**.
- Explain and apply the core ideas in **Proof techniques**.
- Explain and apply the core ideas in **Mathematical induction**.
- Explain and apply the core ideas in **Sets and operations**.
- Explain and apply the core ideas in **Relations and equivalence**.
- Explain and apply the core ideas in **Functions and cardinality**.

A learner should be able to solve representative problems without hints, explain why the method applies, identify assumptions, and check the result. Suggested evidence: a short diagnostic, a worked solution with reasoning, and a spaced-retrieval check after several days.
