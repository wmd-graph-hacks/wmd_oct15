# Topology And Number Theory

A bridge to abstract spaces, algebraic topology, and arithmetic structure.

## Learning outcomes

- Explain and apply the core ideas in **Topological spaces and continuity**.
- Explain and apply the core ideas in **Connectedness and fundamental group**.
- Explain and apply the core ideas in **Divisibility, primes, modular arithmetic**.
- Explain and apply the core ideas in **Fermat, Euler, quadratic reciprocity**.
- Explain and apply the core ideas in **RSA foundations**.
