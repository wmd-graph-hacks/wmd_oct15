# Complex Analysis

Differentiability over ℂ imposes strong structure on functions and integrals.

## Learning outcomes

- Explain and apply the core ideas in **Complex plane and elementary functions**.
- Explain and apply the core ideas in **Holomorphic functions and Cauchy–Riemann**.
- Explain and apply the core ideas in **Contour integration and Cauchy theory**.
- Explain and apply the core ideas in **Taylor and Laurent series**.
- Explain and apply the core ideas in **Residues and conformal mappings**.
