# Single Variable Calculus

Limits, change, accumulation, and infinite processes for functions of one real variable.

## Learning outcomes

- Explain and apply the core ideas in **Limits and continuity**.
- Explain and apply the core ideas in **Derivatives and applications**.
- Explain and apply the core ideas in **Mean Value Theorem**.
- Explain and apply the core ideas in **Riemann integral and FTC**.
- Explain and apply the core ideas in **Integration techniques**.
- Explain and apply the core ideas in **Improper integrals**.
- Explain and apply the core ideas in **Sequences and series**.
- Explain and apply the core ideas in **Power and Taylor series**.
