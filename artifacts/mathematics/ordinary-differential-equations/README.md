# Ordinary Differential Equations

Models of change expressed through derivatives and initial data.

## Learning outcomes

- Explain and apply the core ideas in **First-order methods**.
- Explain and apply the core ideas in **Linear ODEs and systems**.
- Explain and apply the core ideas in **Matrix exponentials and Laplace transforms**.
- Explain and apply the core ideas in **Phase planes, stability, existence and uniqueness**.

A learner should be able to solve representative problems without hints, explain why the method applies, identify assumptions, and check the result. Suggested evidence: a short diagnostic, a worked solution with reasoning, and a spaced-retrieval check after several days.
