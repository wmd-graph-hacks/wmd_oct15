# Linear Algebra

Linear structure, transformations, spectral methods, and approximation.

## Learning outcomes

- Explain and apply the core ideas in **Vector spaces, subspaces, basis**.
- Explain and apply the core ideas in **Linear maps and rank-nullity**.
- Explain and apply the core ideas in **Determinants and invertibility**.
- Explain and apply the core ideas in **Eigenvalues, diagonalization, Jordan form**.
- Explain and apply the core ideas in **Inner products and orthogonality**.
- Explain and apply the core ideas in **Least squares and projections**.
- Explain and apply the core ideas in **Spectral theorem and quadratic forms**.
- Explain and apply the core ideas in **Singular Value Decomposition**.
