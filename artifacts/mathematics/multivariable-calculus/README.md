# Multivariable Calculus

Calculus of functions on Euclidean spaces, including geometry and integral theorems.

## Learning outcomes

- Explain and apply the core ideas in **Vectors and geometry in ℝⁿ**.
- Explain and apply the core ideas in **Partial derivatives and differentiability**.
- Explain and apply the core ideas in **Gradient, chain rule, Jacobian**.
- Explain and apply the core ideas in **Optimization and Lagrange multipliers**.
- Explain and apply the core ideas in **Multiple integrals and change of variables**.
- Explain and apply the core ideas in **Line and surface integrals**.
- Explain and apply the core ideas in **Green, Stokes, and Divergence theorems**.
