# Real Analysis

Rigorous foundations for limits, convergence, integration, and metric structure.

## Learning outcomes

- Explain and apply the core ideas in **Completeness of ℝ**.
- Explain and apply the core ideas in **Function sequences and uniform convergence**.
- Explain and apply the core ideas in **Rigorous continuity and differentiation**.
- Explain and apply the core ideas in **Riemann–Stieltjes and Lebesgue integration**.
- Explain and apply the core ideas in **Metric spaces**.
- Explain and apply the core ideas in **Compactness, connectedness, Baire category**.
