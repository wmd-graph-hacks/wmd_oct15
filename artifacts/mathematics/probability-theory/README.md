# Probability Theory

Axiomatic uncertainty, random variables, distributions, and limit behavior.

## Learning outcomes

- Explain and apply the core ideas in **Probability spaces and conditional probability**.
- Explain and apply the core ideas in **Random variables and distributions**.
- Explain and apply the core ideas in **Joint distributions, expectation, variance**.
- Explain and apply the core ideas in **Named distributions and moment generating functions**.
- Explain and apply the core ideas in **LLN, CLT, and Markov chains**.
