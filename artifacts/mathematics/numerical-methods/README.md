# Numerical Methods

Approximate mathematical solutions while controlling error, stability, and computational cost.

## Learning outcomes

- Explain and apply the core ideas in **Floating-point error, conditioning, stability**.
- Explain and apply the core ideas in **Root finding**.
- Explain and apply the core ideas in **Interpolation and splines**.
- Explain and apply the core ideas in **Numerical differentiation and integration**.
- Explain and apply the core ideas in **Numerical linear algebra**.
- Explain and apply the core ideas in **Numerical ODEs**.

A learner should be able to solve representative problems without hints, explain why the method applies, identify assumptions, and check the result. Suggested evidence: a short diagnostic, a worked solution with reasoning, and a spaced-retrieval check after several days.
