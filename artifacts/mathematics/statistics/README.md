# Statistics

Use data to estimate parameters, quantify uncertainty, test claims, and model relationships.

## Learning outcomes

- Explain and apply the core ideas in **Point estimation and maximum likelihood**.
- Explain and apply the core ideas in **Confidence intervals and hypothesis tests**.
- Explain and apply the core ideas in **ANOVA and regression**.
- Explain and apply the core ideas in **Nonparametric and Bayesian methods**.
- Explain and apply the core ideas in **Experimental design**.

## Assessment evidence

A learner should be able to solve representative problems without hints, explain why the method applies, identify assumptions, and check the result. Suggested evidence: a short diagnostic, a worked solution with reasoning, and a spaced-retrieval check after several days.
