# Discrete Mathematics And Combinatorics

Finite structures, counting, recurrences, and graphs.

## Learning outcomes

- Explain and apply the core ideas in **Counting principles and binomial theorem**.
- Explain and apply the core ideas in **Recurrences and generating functions**.
- Explain and apply the core ideas in **Inclusion-exclusion**.
- Explain and apply the core ideas in **Graph theory**.
