# Databases

Relational: Entity-relationship modeling, normalization (1NF through BCNF), SQL (joins, subqueries, window functions, CTEs), indexes (B-tree, hash, composite, covering), query planning and execution plans, transactions and ACID, isolation levels and anomalies (dirty reads, phantom reads, write skew), MVCC, locking; NoSQL: Document stores (MongoDB), key-value stores (Redis, DynamoDB), wide-column stores (Cassandra, HBase), graph databases (Neo4j), time-series databases, search engines (Elasticsearch); Scaling: Replication (leader-follower, multi-leader, leaderless), sharding and partitioning strategies, consistent hashing, read replicas, connection pooling, database migrations

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
