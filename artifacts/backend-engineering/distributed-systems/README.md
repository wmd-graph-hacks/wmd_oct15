# Distributed Systems

CAP and PACELC theorems, consistency models (strong, eventual, causal, linearizability), consensus algorithms (Paxos, Raft), leader election, distributed transactions (two-phase commit, sagas), clocks and ordering (Lamport, vector clocks), failure modes (partial failure, network partitions, split brain), idempotency, retries with exponential backoff and jitter, circuit breakers, bulkheads, timeouts

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
