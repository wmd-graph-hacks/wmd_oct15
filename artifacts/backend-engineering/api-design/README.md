# API Design

REST principles and resource modeling, HTTP methods and status codes, GraphQL schemas and resolvers, gRPC and Protocol Buffers, pagination (offset, cursor), versioning strategies, rate limiting, idempotency keys, API documentation (OpenAPI)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.

- [pagination: mechanisms and methods](./pagination/README.md) (`backend-engineering-api-design-pagination`)
- [API documentation: applications and analysis](./api-documentation/README.md) (`backend-engineering-api-design-api-documentation`)

Ask the learner to explain one concept without notes, work a changed example, and identify an assumption or limitation.
