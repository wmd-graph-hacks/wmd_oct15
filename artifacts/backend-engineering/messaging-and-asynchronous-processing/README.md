# Messaging and Asynchronous Processing

Message queues (RabbitMQ, SQS), publish-subscribe, event streaming (Kafka), delivery semantics (at-most-once, at-least-once, exactly-once), dead-letter queues, event sourcing, CQRS, stream processing, background job processing

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
