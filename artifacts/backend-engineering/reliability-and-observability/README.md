# Reliability and Observability

Structured logging, metrics (counters, gauges, histograms), distributed tracing (OpenTelemetry), SLIs, SLOs, and error budgets, health checks, graceful shutdown, load testing, capacity planning, performance profiling

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
