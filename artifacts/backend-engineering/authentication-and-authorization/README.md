# Authentication and Authorization

Sessions and cookies, password hashing (bcrypt, Argon2), JWT, OAuth 2.0 flows, OpenID Connect, role-based and attribute-based access control, API keys, secrets management, input validation, CSRF and CORS

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
