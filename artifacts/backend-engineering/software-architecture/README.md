# Software Architecture

Monolith vs. microservices, modular monoliths, domain-driven design (bounded contexts, aggregates), hexagonal and clean architecture, service boundaries, API gateways, service discovery, backend-for-frontend pattern, design patterns (factory, strategy, observer, adapter, decorator)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
