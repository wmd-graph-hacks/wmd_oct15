# Optics and Waves

Wave equation, superposition, interference (Young’s double slit, thin films), diffraction (single and multiple slit, gratings), polarization, Fresnel and Fraunhofer diffraction, geometric optics (lenses, mirrors), laser basics

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
