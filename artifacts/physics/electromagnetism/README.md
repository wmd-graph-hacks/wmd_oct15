# Electromagnetism

Coulomb’s law, electric fields and Gauss’s law, electric potential, conductors and capacitors, dielectrics, magnetostatics, Biot-Savart law, Ampère’s law, electromagnetic induction (Faraday’s law), inductance, Maxwell’s equations (differential and integral forms), electromagnetic waves, boundary conditions, Poynting vector, radiation basics, multipole expansion

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
