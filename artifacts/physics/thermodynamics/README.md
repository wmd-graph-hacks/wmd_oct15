# Thermodynamics

Zeroth, first, second, and third laws, heat engines and refrigerators, Carnot cycle, entropy, thermodynamic potentials (internal energy, enthalpy, Helmholtz, Gibbs), Maxwell relations, phase transitions and the Clausius-Clapeyron equation

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
