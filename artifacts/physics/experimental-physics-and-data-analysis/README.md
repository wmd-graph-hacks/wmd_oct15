# Experimental Physics and Data Analysis

Measurement and uncertainty, error propagation, significance, least-squares fitting, lab instrumentation, oscilloscopes, signal processing basics, scientific computing (Python, MATLAB, or similar)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
