# Statistical Mechanics

Microstates and macrostates, ensembles (microcanonical, canonical, grand canonical), partition functions, Boltzmann distribution, Maxwell-Boltzmann distribution, Bose-Einstein and Fermi-Dirac statistics, blackbody radiation, ideal gases and quantum gases, introduction to phase transitions and the Ising model

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
