# Mathematical Methods for Physics

Vector calculus, tensors (intro), Fourier analysis, special functions (Bessel, Legendre, Hermite), Green’s functions, complex methods, group theory (intro)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
