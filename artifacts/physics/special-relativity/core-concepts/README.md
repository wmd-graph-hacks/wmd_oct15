# Postulates: foundations

## Core idea

This lesson narrows **Special Relativity** to a connected set of concepts. The scope terms below come from the subject outline; use them as a map of the model, not as a vocabulary list to memorize in isolation.

Special relativity keeps the speed of light invariant across inertial frames. Lorentz transformations relate space and time measurements; simultaneity can depend on frame. For this unit, focus on **Postulates** and how it fits the wider model.

## How to reason through the material

Draw the system and choose coordinates and sign conventions. State approximations, derive the relation before inserting values, preserve units, and check limiting cases or conservation laws.

For each item, make a three-column note: what it describes, what evidence or operation identifies it, and how changing one relevant condition changes the prediction. Then draw arrows between the items to show whether they represent prerequisites, steps in a process, alternative models, or ways of measuring the same system. Do not assume that two adjacent terms have a causal relationship unless the model or evidence supports it.

## Worked study example

Choose **Postulates** from the list. State a concrete question that can be answered using it; write down the system boundary, observations available, assumptions, and expected result. Work from the definition or governing model to the result, and annotate each step with why it is valid. Change one condition and predict the effect before looking up the answer. If the prediction fails, identify whether the cause is a violated assumption, a measurement issue, or a mistaken link between concepts.
