# Classical Machine Learning

Supervised learning: Linear regression, logistic regression, regularization (L1, L2, elastic net), decision trees, random forests, gradient boosting (XGBoost, LightGBM), support vector machines (kernel methods), k-nearest neighbors, naive Bayes; Unsupervised learning: k-means, hierarchical clustering, Gaussian mixture models, DBSCAN, dimensionality reduction (PCA, t-SNE, UMAP), anomaly detection; Model evaluation: Train/validation/test splits, cross-validation, bias-variance tradeoff, overfitting and underfitting, precision, recall, F1, ROC-AUC, calibration, hyperparameter tuning; Feature engineering: Encoding categorical data, scaling, handling missing values, feature selection, leakage prevention

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
