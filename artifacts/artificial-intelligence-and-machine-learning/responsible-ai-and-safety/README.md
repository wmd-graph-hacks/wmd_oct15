# Responsible AI and Safety

Fairness metrics and bias mitigation, interpretability (SHAP, LIME, attention analysis, mechanistic interpretability), privacy (differential privacy, federated learning), adversarial robustness, data poisoning, prompt injection, alignment basics, evaluation of harmful outputs, model documentation (model cards)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
