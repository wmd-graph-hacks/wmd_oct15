# Neural Networks and Deep Learning

Perceptron, multilayer perceptrons, activation functions, backpropagation, loss functions, weight initialization, optimizers (SGD, momentum, Adam, AdamW), regularization (dropout, batch normalization, layer normalization, weight decay), learning rate schedules, convolutional neural networks (CNNs), recurrent networks (RNN, LSTM, GRU), attention mechanisms, transformers, autoencoders, variational autoencoders (VAEs), generative adversarial networks (GANs), diffusion models, contrastive learning

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
