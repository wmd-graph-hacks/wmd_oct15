# Computer Vision

Image representation, convolution and filtering, classic features (SIFT, HOG), CNN architectures (ResNet, EfficientNet), object detection (YOLO, Faster R-CNN), semantic and instance segmentation, vision transformers (ViT), image generation

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
