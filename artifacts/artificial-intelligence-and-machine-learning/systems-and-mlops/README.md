# Systems and MLOps

GPU and accelerator architecture, mixed-precision training, distributed training (data parallelism, model parallelism, pipeline parallelism), experiment tracking, model versioning, feature stores, model serving (batching, latency optimization), quantization, pruning, distillation, monitoring for data and concept drift, A/B testing for models

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
