# Natural Language Processing

Tokenization, word embeddings (Word2Vec, GloVe), language modeling, sequence-to-sequence models, transformer-based language models (BERT, GPT-style), pretraining and fine-tuning, instruction tuning, retrieval-augmented generation (RAG), prompt engineering, evaluation metrics (BLEU, ROUGE, perplexity), text classification and named entity recognition

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
