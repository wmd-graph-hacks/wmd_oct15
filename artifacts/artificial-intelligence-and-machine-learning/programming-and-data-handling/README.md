# Programming and Data Handling

Python for data science, NumPy, pandas, data cleaning and preprocessing, exploratory data analysis, visualization (Matplotlib, Seaborn), SQL for data access, version control, reproducible experiments, Jupyter notebooks

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
