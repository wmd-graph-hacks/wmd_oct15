# Probabilistic and Bayesian Methods

Maximum likelihood vs. maximum a posteriori estimation, graphical models (Bayesian networks, Markov random fields), hidden Markov models, Markov chain Monte Carlo (MCMC), variational inference, expectation-maximization (EM), Gaussian processes, Bayesian neural networks (intro)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
