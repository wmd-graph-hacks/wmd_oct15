# Mathematical Foundations

Linear algebra (vectors, matrices, eigendecomposition, SVD), multivariable calculus (gradients, Jacobians, Hessians, chain rule), probability (distributions, Bayes’ theorem, expectation), statistics (estimators, hypothesis testing), information theory (entropy, KL divergence, cross-entropy, mutual information), numerical optimization

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
