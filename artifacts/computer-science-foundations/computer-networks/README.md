# Computer Networks

OSI and TCP/IP models, IP addressing and subnetting, TCP (handshake, flow control, congestion control), UDP, DNS resolution, HTTP/1.1, HTTP/2, HTTP/3 and QUIC, TLS handshake, sockets, WebSockets, proxies, load balancing

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
