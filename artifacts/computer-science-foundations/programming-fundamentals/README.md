# Programming Fundamentals

Mastery of one primary language (for example Python, Java, Go, or C#), data types and control flow, functions and closures, object-oriented design (encapsulation, inheritance, polymorphism), functional programming concepts (immutability, higher-order functions), error handling, memory management (garbage collection, manual management), concurrency models (threads, async/await, goroutines, actors)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
