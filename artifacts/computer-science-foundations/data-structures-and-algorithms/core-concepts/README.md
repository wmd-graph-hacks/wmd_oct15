# Arrays: foundations

## Core idea

This lesson narrows **Data Structures and Algorithms** to a connected set of concepts. The scope terms below come from the subject outline; use them as a map of the model, not as a vocabulary list to memorize in isolation.

A data structure organizes information for operations; an algorithm defines the steps that use it. Analyze time and space as input grows and verify edge cases. For this unit, focus on **Arrays** and how it fits the wider model.

## How to reason through the material

Trace a small input by hand, state the invariant that should remain true, and account for time, space, and edge cases. Use a test case that distinguishes the intended behavior from a plausible bug.

For each item, make a three-column note: what it describes, what evidence or operation identifies it, and how changing one relevant condition changes the prediction. Then draw arrows between the items to show whether they represent prerequisites, steps in a process, alternative models, or ways of measuring the same system. Do not assume that two adjacent terms have a causal relationship unless the model or evidence supports it.

## Worked study example

Choose **Arrays** from the list. State a concrete question that can be answered using it; write down the system boundary, observations available, assumptions, and expected result. Work from the definition or governing model to the result, and annotate each step with why it is valid. Change one condition and predict the effect before looking up the answer. If the prediction fails, identify whether the cause is a violated assumption, a measurement issue, or a mistaken link between concepts.

## Check your understanding

1. Explain the difference between the first two concepts in your own words, including one condition that changes how they should be used.
2. Give an example where a learner could recognize the vocabulary but still apply the model incorrectly. State the correction.
3. What observation, calculation, or test would most directly challenge your explanation?

## Retrieval practice

Close the lesson and reconstruct the concept map from memory. Work one example without notes, then explain the assumptions and one limitation. Revisit the hardest step after a delay and solve a changed example.
