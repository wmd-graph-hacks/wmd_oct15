# Data Structures and Algorithms

Arrays, linked lists, stacks, queues, hash tables, trees (binary search trees, AVL, red-black, B-trees, tries), heaps, graphs (BFS, DFS, shortest paths, minimum spanning trees), sorting and searching, dynamic programming, greedy algorithms, divide and conquer, Big-O analysis

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
