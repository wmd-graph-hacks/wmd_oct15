# Operating Systems Fundamentals

Processes and threads, context switching, CPU scheduling, synchronization primitives (mutexes, semaphores, condition variables), deadlocks, virtual memory and paging, file systems, inter-process communication, system calls, I/O models (blocking, non-blocking, epoll)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
