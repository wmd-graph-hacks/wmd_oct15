# Practical Labs and Experience

Capture the Flag (CTF) competitions, home lab setup (virtual networks, vulnerable VMs such as Metasploitable and DVWA), platforms such as Hack The Box, TryHackMe, and OverTheWire, bug bounty programs, open-source contributions to security tools

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
