# Network Security

Network segmentation, firewalls (stateful, next-generation), intrusion detection and prevention systems (Snort, Suricata), VPN architectures, DNS security (DNSSEC, DNS over HTTPS), packet analysis (Wireshark, tcpdump), network protocol vulnerabilities, denial-of-service attacks and defenses, zero trust network access, Wi-Fi security

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
