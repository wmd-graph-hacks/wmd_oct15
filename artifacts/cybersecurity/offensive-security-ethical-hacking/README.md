# Offensive Security (Ethical Hacking)

Reconnaissance (OSINT, passive and active scanning), enumeration, vulnerability assessment, exploitation methodology, post-exploitation, lateral movement, privilege escalation, social engineering awareness, password attacks, wireless attacks, pentesting methodology (PTES, OWASP Testing Guide), rules of engagement, report writing

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
