# Defensive Security and Security Operations

Security operations center (SOC) workflows, log management, SIEM (Splunk, Elastic Security, Microsoft Sentinel), detection engineering (Sigma rules, YARA), threat hunting, alert triage, incident response lifecycle (NIST SP 800-61: preparation, detection, containment, eradication, recovery, lessons learned), digital forensics (disk, memory, network), chain of custody, evidence handling

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
