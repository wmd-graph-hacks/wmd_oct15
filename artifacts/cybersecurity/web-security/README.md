# Web Security

Browser security model (same-origin policy, CORS, cookies and their attributes, Content Security Policy, subresource integrity), session management, clickjacking, HTTP security headers, web application firewalls, API security (broken object-level authorization, mass assignment)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.

## Subtopics

- [Browser security model: foundations](./core-concepts/README.md) (`cybersecurity-web-security-core-concepts`)
- [web application firewalls: mechanisms and methods](./web-application-firewalls/README.md) (`cybersecurity-web-security-web-application-firewalls`)

## Assessment evidence

Ask the learner to explain one concept without notes, work a changed example, and identify an assumption or limitation.
