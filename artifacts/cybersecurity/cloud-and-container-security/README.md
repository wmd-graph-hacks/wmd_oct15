# Cloud and Container Security

Shared responsibility model, cloud IAM misconfiguration, storage bucket exposure, cloud security posture management (CSPM), container image security, Kubernetes security (RBAC, pod security standards, network policies, admission controllers), secrets in cloud environments, cloud logging and auditing

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
