# Security Foundations

The CIA triad (confidentiality, integrity, availability) and extensions (authenticity, non-repudiation), threat modeling (STRIDE, attack trees), risk assessment and management, security principles (least privilege, defense in depth, fail securely, zero trust), security governance and policy, frameworks (NIST CSF, ISO/IEC 27001, CIS Controls), security economics

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
