# Operating System and Host Security

Linux hardening, file permissions and ACLs, SELinux and AppArmor, Windows security architecture, Active Directory security, privilege escalation (Linux and Windows), memory protections (ASLR, DEP/NX, stack canaries, control-flow integrity), sandboxing and containers, endpoint detection and response (EDR), secure boot, trusted platform module (TPM)

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
