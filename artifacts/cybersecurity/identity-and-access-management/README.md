# Identity and Access Management

Authentication factors, multi-factor authentication (TOTP, WebAuthn, FIDO2), single sign-on, federation (SAML, OAuth, OIDC), directory services (LDAP, Active Directory), privileged access management, access reviews, identity governance, passwordless authentication

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
