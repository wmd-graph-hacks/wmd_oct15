# Threat Intelligence and Frameworks

MITRE ATT&CK, the Cyber Kill Chain, Diamond Model, indicators of compromise (IOCs), threat actor profiling, threat intelligence platforms, sharing standards (STIX, TAXII), adversary emulation

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
