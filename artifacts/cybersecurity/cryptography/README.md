# Cryptography

Symmetric: Block ciphers (AES), stream ciphers, modes of operation (CBC, CTR, GCM), padding attacks; Asymmetric: RSA, Diffie-Hellman, elliptic curve cryptography (ECDSA, ECDH), key exchange; Hashing and integrity: SHA-2, SHA-3, HMAC, collision resistance, password hashing (bcrypt, scrypt, Argon2); Signatures and PKI: Digital signatures, certificate authorities, X.509, certificate chains, revocation (CRL, OCSP), certificate transparency; Protocols: TLS 1.3 internals, SSH, IPsec, Signal protocol basics; Advanced: Zero-knowledge proofs, homomorphic encryption (intro), post-quantum cryptography overview, key management lifecycle

## Learning outcomes

- Define the main terms and identify assumptions.
- Explain how the central ideas connect to each other and the wider subject.
- Apply a standard method or interpret an example in context.
- Check a conclusion and describe a limitation.
